# BongChzzk

치지직(chzzk.naver.com) 라이브/다시보기 영상이 버퍼링에 걸려 멈추면, **페이지 전체 새로고침 없이** 플레이어만 자동 복구하는 크롬 확장 프로그램입니다.

## 설치
1. 압축 파일을 풀어 `BongChzzk` 폴더를 준비합니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 폴더 선택
5. 치지직 탭이 열려 있었다면 그 탭은 한 번 새로고침해 주세요(최초 1회).

## 동작 방식
1초마다 영상이 실제로 진행 중인지 확인하고, 일시정지가 아닌데 설정 시간(기본 5초) 이상 멈춰 있으면 단계적으로 복구합니다.
1. 재생 재개 + 라이브는 버퍼 끝(최신 지점)으로 살짝 이동
2. 일시정지 → 재생으로 플레이어 재시작
3. 스트림 다시 불러오기 (플레이어 재시도 버튼 클릭 / 라이브 엣지 점프 / 일반 소스는 load)
4. 사이트 내부 이동으로 플레이어 재마운트 (페이지 새로고침 아님)

복구 사이에는 대기 시간(기본 10초, 점점 늘어남)이 있어 무한 반복을 막고, 15초 정상 재생되면 단계가 초기화됩니다.

## 화질 1080p 고정
라이브(`/live/`)·다시보기(`/video/`) 페이지에서 플레이어 설정(톱니바퀴) → 화질 메뉴를 잠깐 투명하게 열어 1080p를 선택하고 닫습니다(페이지 새로고침 없음). 1080p가 없으면 그 아래 가장 높은 화질을 고릅니다.
3초마다 현재 화질을 확인해 다르면 다시 적용하고, 영상이 새로 로드되거나 버퍼링 복구 후에도 다시 적용합니다. 실패하면 점점 간격을 늘려 재시도합니다.
직접 화질 메뉴에서 다른 화질을 고르면 10분간은 바꾸지 않습니다. 팝업에서 끄거나 목표 화질(1080p/720p/480p/360p)을 바꿀 수 있습니다.

## 설정
툴바 아이콘 클릭: 사용 여부, 버퍼링 판정 시간, 복구 간격, 화면 알림, 화질 고정/목표 화질, 복구 횟수 확인.
콘솔(F12)에 `[BongChzzk]` 로그가 남습니다.

## 업데이트

팝업의 **업데이트 확인**을 누르면 GitHub 최신 릴리스(`Baegovda/BongChzzk`)와 현재 버전을 비교합니다. 새 버전이 있으면 **zip 다운로드**로 받아 기존 폴더에 덮어쓴 뒤, **확장 프로그램 관리**에서 새로고침(↻)하세요.

## 릴리스 방법

1. `manifest.json`, `package.json`의 `version`을 올립니다.
2. `CHANGELOG.md` 맨 위에 `## [x.y.z] - YYYY-MM-DD` 섹션을 추가합니다.
3. `node --test` 후 `main`에 커밋/푸시합니다.
4. `git tag -a vX.Y.Z -m "vX.Y.Z" && git push origin vX.Y.Z` → Actions가 `bongchzzk-X.Y.Z.zip` 릴리스를 만듭니다.
