# BongChzzk

치지직(chzzk.naver.com) 라이브/다시보기 영상이 버퍼링에 걸려 멈추면, **페이지 전체 새로고침 없이** 플레이어만 자동 복구하는 크롬 확장 프로그램입니다.

## 설치
1. 압축 파일을 풀어 `BongChzzk` 폴더를 준비합니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 폴더 선택
5. 치지직 탭이 열려 있었다면 그 탭은 한 번 새로고침해 주세요(최초 1회).

## 동작 방식
1초마다 영상이 실제로 진행 중인지 확인하고, 일시정지가 아닌데 설정 시간(기본 5초) 이상 멈춰 있으면 단계적으로 복구합니다.
1. 재생 재개 + 라이브는 버퍼 끝(최신 지점)으로 살짝 이동
2. 일시정지 → 재생으로 플레이어 재시작
3. 스트림 다시 불러오기 (플레이어 재시도 버튼 클릭 / 라이브 엣지 점프 / 일반 소스는 load)
4. 사이트 내부 이동으로 플레이어 재마운트 (페이지 새로고침 아님)

복구 사이에는 대기 시간(기본 10초, 점점 늘어남)이 있어 무한 반복을 막고, 15초 정상 재생되면 단계가 초기화됩니다.

## 화질 1080p 고정
라이브(`/live/`)·다시보기(`/video/`) 페이지에서 플레이어 설정(톱니바퀴) → 화질 메뉴를 잠깐 투명하게 열어 1080p를 선택하고 닫습니다(페이지 새로고침 없음). 1080p가 없으면 그 아래 가장 높은 화질을 고릅니다.
3초마다 현재 화질을 확인해 다르면 다시 적용하고, 영상이 새로 로드되거나 버퍼링 복구 후에도 다시 적용합니다. 실패하면 점점 간격을 늘려 재시도합니다.
직접 화질 메뉴에서 다른 화질을 고르면 10분간은 바꾸지 않습니다. 팝업에서 끄거나 목표 화질(1080p/720p/480p/360p)을 바꿀 수 있습니다.

## 팔로잉 채널 자동 새로고침

탭이 화면에 보이고 사이드바 "팔로잉 채널"(또는 `/following` 페이지)이 있을 때만, 기본 5초마다 페이지 새로고침 없이 목록을 갱신합니다.

1. 해당 영역에 새로고침 버튼(`aria-label`/`title`/텍스트 "새로고침", `refresh` 클래스)이 있으면 누릅니다.
2. 없으면 `https://api.chzzk.naver.com/service/v1/channels/followings/live`(로그인 쿠키 포함)로 라이브 채널 목록만 확인하고, 바뀌었을 때 `focus`/`visibilitychange` 이벤트로 사이트가 스스로 다시 불러오게 유도합니다.
3. 실패가 이어지면 간격을 두 배씩 늘립니다(최대 5분). 스크롤 위치는 유지합니다.

팝업에서 켜기/끄기와 간격(5/10/30/60초)을 바꿀 수 있습니다. 선택자와 이벤트 기반 재요청은 실제 사이트에서 검증되지 않은 추정입니다.

## 1.3.0 추가 기능

- **화질 고정(수정)**: 설정 버튼 → 화질 행 클릭 후 목표 화질 항목에 Enter 키 입력으로 선택하고, `.pzp-pc-setting-intro-quality`의 `value`로 적용 여부를 확인합니다. 메뉴는 보이지 않게 열고 닫습니다. 새 방송/광고 종료/영상 소스 변경/URL 변경 시와 3초마다 재확인합니다.
- **선명한 화면 항상 켜기**: 플레이어에 `pzp-pc--filter`가 없으면 "선명한 화면" 행을 한 번 클릭합니다(10초에 최대 1회).
- **시청자 수**: `/live/<채널ID>`에서 탭이 보일 때 `api.chzzk.naver.com/polling/v3.1/channels/<ID>/live-status`를 1초마다 한 번 조회해 채팅 헤더와 플레이어 왼쪽 위에 표시합니다. 실패하면 `-`를 표시하고 간격을 늘립니다.
- **주간 랭킹 가리기**: CSS(`:has`)와 JS 보조 규칙으로 채팅창의 랭킹 위젯을 숨깁니다.
- **채팅 글씨 크기**: 기본(변경 안 함) 또는 12~28px.
- **방향키 이동**: ←/→로 5초(선택 가능) 이동. 입력창 포커스 중이거나 Ctrl/Alt/Cmd를 누르면 동작하지 않습니다. 사이트의 기본 방향키 동작은 막습니다.

## 관심 스트리머 자동 이동 (1.5.0)

팝업 **관심 스트리머 자동 이동**에 채널 주소(`chzzk.naver.com/<ID>`, `/live/<ID>`)나 32자리 ID를 붙여넣거나 **현재 보는 채널 추가**를 누르세요. 치지직 탭이 하나라도 열려 있으면 5초마다 `live-status`를 확인하고, 방송이 꺼짐→켜짐으로 바뀌면 1초 알림 후 그 방송으로 이동합니다. 처음 확인할 때 이미 방송 중이면 이동하지 않습니다(**지금 방송 중이면 이동** 버튼 사용). 목록 순서상 앞의 스트리머가 우선입니다.

## 넓은 화면 자동 (1.5.0)

라이브/다시보기에 들어가면 최대 약 10초 동안 플레이어를 기다렸다가 넓은 화면 버튼을 한 번 누릅니다. 버튼은 클래스(`viewmode`/`wide`/`screen-mode`)와 aria-label/title/텍스트(넓은 화면/와이드/wide)로 찾는 추정 방식이며, 콘솔(`console.debug`, 상세 수준)에 `[BongChzzk] 넓은 화면 후보`가 찍힙니다.

## 1.6.1 광고 방지 개선

플레이어 안 "AD 1/1", "N 초 후 SKIP", "SKIP" 문구로 광고를 감지해 SKIP이 나오면 바로 누르고, 광고 영상은 음소거·16배속으로 넘깁니다. 콘솔에 `[BongChzzk] 광고 감지/광고 SKIP 클릭/광고 종료`가 기록됩니다(실험적 기능).

## 업데이트

팝업의 **업데이트 확인**을 누르면 GitHub 최신 릴리스(`Baegovda/BongChzzk`)와 현재 버전을 비교합니다. 새 버전이 있으면 **zip 다운로드**로 받아 기존 폴더에 덮어쓴 뒤, **확장 프로그램 관리**에서 새로고침(↻)하세요.

## 딸깍 업데이트 (1.4.0)

팝업에서 **업데이트 확인** → 새 버전이면 **지금 업데이트** → 업데이트 전용 탭이 열리면 **폴더 선택/업데이트 시작**을 누르세요(팝업은 폴더 선택 창이 뜨면 닫히므로 별도 탭에서 진행합니다). 처음에는 폴더 선택 창에서 `chrome://extensions`에 불러온 BongChzzk 폴더(`manifest.json`이 있는 폴더)를 고르세요. 크롬은 다운로드·바탕화면 폴더 자체는 선택하지 못하게 막으므로 그 안의 BongChzzk 폴더를 골라야 합니다. 선택한 폴더는 기억되어 다음부터는 권한 확인만 합니다. 최신 릴리스 zip을 받아 메모리에서 모두 푼 뒤 폴더에 덮어쓰고 확장 프로그램을 다시 로드합니다. (기존 파일은 덮어쓰기만 하고 삭제하지 않습니다.)

채팅 글씨 크기는 팝업 슬라이더(12~28px)로 바로 바뀌고, **기본** 버튼은 원래 크기로 되돌립니다.

업데이트 페이지 맨 위에 `현재 → 새 버전`이 크게 표시됩니다. 바뀐 파일만 쓰고 `manifest.json`은 마지막에 씁니다. 도중에 끊기면 업데이트 페이지를 다시 열어 **중단된 업데이트가 있습니다. 이어서 완료**를 누르세요. (1.5.1)

## 릴리스 방법

1. `manifest.json`, `package.json`의 `version`을 올립니다.
2. `CHANGELOG.md` 맨 위에 `## [x.y.z] - YYYY-MM-DD` 섹션을 추가합니다.
3. `node --test` 후 `main`에 커밋/푸시합니다.
4. `git tag -a vX.Y.Z -m "vX.Y.Z" && git push origin vX.Y.Z` → Actions가 `bongchzzk-X.Y.Z.zip` 릴리스를 만듭니다.
