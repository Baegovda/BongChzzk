BongExtend 번역

현재 페이지의 보이는 글을 Gemini로 번역합니다. 키는 이 브라우저에만 저장됩니다.

무료 키는 Google AI Studio에서 만듭니다. 키 페이지: aistudio.google.com/apikey

모델
혼잡할 때 대체 모델

기본 모델이 혼잡(503)하거나 없으면(404) 대체 모델로 넘어갑니다. 그래도 안 되면 나머지 기본 제공 모델을 한 번 더 시도합니다. 키 오류와 할당량 초과는 넘어가지 않습니다.

기본값은 한국어입니다. 원문 언어는 문장마다 자동으로 감지합니다.

기본값은 꺼짐입니다. 켜면 화면에 들어온 문장 중 커서에 가까운 것부터 다음 묶음으로 보냅니다. 이미 보낸 요청은 취소하지 않습니다.

기본값은 켜짐입니다. 번역을 기다리는 동안 은은한 프리즘 빛이 돌고, 번역이 도착하면 무지개 스캔이 글을 지나가며 원문이 번역문으로 바뀝니다. 끄면 바로 바꿉니다. 시스템에서 움직임 줄이기를 켠 경우에는 짧은 페이드만 사용합니다.

아낀 문장과 API 호출은 누적입니다. 캐시를 지워도 이 숫자는 남고, 통계 초기화만 0으로 되돌립니다. 용량은 번역문과 키의 UTF-8 크기 근사치입니다.

기본 보관 기간은 90일입니다. 기간이 지난 항목을 지우고, 용량 한도를 넘으면 마지막 사용이 오래된 항목부터 지웁니다. 삭제 안 함과 제한 없음을 같이 고르면 자동으로 지우지 않습니다.

화면에 있는 키와 모델 설정을 JSON으로 저장하거나 다시 불러옵니다. 파일에 API 키가 들어 있으니 남에게 보내지 마세요. manifest의 key 때문에 다른 폴더에서 다시 로드해도 같은 확장 프로그램 ID를 쓰며, 확장 프로그램을 제거하지 않았다면 저장소가 유지됩니다. 완전히 삭제한 뒤에는 이 파일로 다시 가져오세요.

개인정보

번역하는 문장은 사용자의 API 키로 Google Gemini API에 전송됩니다. 이 확장 프로그램의 서버는 없습니다. 키와 번역 캐시는 이 기기의 chrome.storage.local과 IndexedDB에만 있습니다.

무료 등급에서는 입력한 글이 Google 모델 개선에 쓰일 수 있습니다. 유료 등급의 데이터 사용 여부는 모델마다 다르니 요금 페이지를 확인하세요.
